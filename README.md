# AI/ML/Data Science Projects 🤖📊

Personal repository for Artificial Intelligence, Machine Learning, and Data Science projects implemented in Python, R, and other technologies.

## ⚠️ Educational Purpose & Disclaimers

This is a **personal learning repository** documenting my journey through AI, ML, and Data Science. The primary purpose is **educational exploration** and hands-on learning of different algorithms, techniques, and methodologies.

- **Educational Purpose Only**: This repository is designed for learning and experimentation, not production use
- **Experimental Results**: The results and scores achieved may not represent optimal performance - they are exploratory attempts to understand how different algorithms respond to various datasets and scenarios
- **Learning Focus**: Projects prioritize understanding concepts and implementation over achieving state-of-the-art results
- **Non-Production Code**: While functional, the code is primarily for educational purposes and may not follow production-ready standards

The projects document various approaches and their outcomes, providing insights into algorithm behavior rather than pursuing the highest possible scores.

## 📁 Repository Structure

This repository is organized by discipline and technology, allowing for diverse projects across different domains:

```
├── machine-learning/      # Classical ML algorithms and techniques
│   ├── supervised/        # Supervised learning projects
│   └── unsupervised/      # Unsupervised learning projects
├── deep-learning/         # Neural networks and deep learning
├── llm-projects/          # Large Language Models and NLP
├── data-science/          # Statistical analysis and hypothesis testing
│   ├── factor_analysis/   # Factor analysis projects
│   └── hypothesis_testing/ # Statistical hypothesis testing
└── mlops/                 # Deployment and production workflows
```

## 🚀 How to Navigate

**Browse by category**: Each folder contains projects of similar nature
**Check individual READMEs**: Each project has its own documentation

## 📈 Project Standards

Each project follows a consistent structure:
```
project-name/
├── README.md           # Project description and instructions
├── data/              # Project-specific datasets
├── notebook/          # Jupyter notebooks (Python projects)
├── *.Rmd & *.html     # R Markdown files and outputs (R projects)
└── requirements.txt   # Python dependencies

```

## 🛠️ Technologies Used

- **Python**: Machine learning, deep learning, and NLP projects with virtual environments
- **R**: Statistical analysis and hypothesis testing with R Markdown
- **Jupyter Notebooks**: Interactive data analysis and model development
- **Key Libraries**: pandas, numpy, scikit-learn, transformers, torch, ggplot2
