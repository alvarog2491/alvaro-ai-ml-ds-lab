# University Faculty Salary Analysis

## Overview
This project analyzes factors influencing university faculty salaries using the Salaries dataset from the "car" package in R. The study employs multiple linear regression models to identify the most significant predictors of academic compensation.

## Methodology
The analysis systematically develops and evaluates different regression models, with particular attention to multicollinearity issues and model performance. Key techniques include:
- Exploratory data analysis with correlation matrices
- Model comparison and evaluation
- Logarithmic transformations to capture non-linear relationships
- Residual analysis for model validation

## Analysis Approach
The study addresses multicollinearity issues between predictor variables and explores various model specifications to optimize predictive performance. Different transformations are tested to capture potential non-linear relationships in the data.

## Dataset
The analysis uses data from 397 university professors with variables including academic rank, discipline, years of service, years since PhD, gender, and salary in dollars.

Dataset link: https://rdrr.io/cran/carData/man/Salaries.html

## Final Model
The analysis concludes with a recommended model specification and thorough validation through residual analysis to verify statistical assumptions.
